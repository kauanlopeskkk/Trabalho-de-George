# Layout - Flexbox (WhatsApp UI)

Este projeto é um layout de **interface estilo WhatsApp** feito usando **Flexbox** e **CSS**

## Funcionalidades 

-Header com foto circular do contato e status
- Área de mensagens com balões alinhados:
- mensagem do "Amanda" (esquerda)
- mensagem do "Usuario" (direita)
-Campo de digitação e botão de enviar
-Responsivo(ajustes para telas menores)

## Tecnologias Usadas

- HTML
- CSS (Flexbox)

## Para Executar

1 - Abra arquivo 'index.html' no navegador
        **ou**
2 - Use um servidor local (ex:VsCode Live Server)

## Estrutura do projeto

Layout-Flexbox -> Pasta raiz
-"index.html" -> Página principal
- "Css/FlexboxStyle -> Estilos do Layout
- "Img/" -> imagens (ex: foto do avatar)

## Personalizações
- Trocar o avatar: altere a imagem em 'img/' e ajuste o 'src' do '<img>'
- Ajustar tamanho do avatar: modifique 'width//height' na classe '.contact-avatar'
-utilizando o media para transições da largura do site
